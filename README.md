# Jarvis Projetor — atualizações

Arquivos de atualização do **Jarvis Projetor**, um launcher para projetor Android controlado pelo controle remoto.

O aplicativo consulta as [Releases](../../releases) deste repositório para saber se existe versão nova, baixa o arquivo `.apk` e pede a confirmação da instalação. Cada release usa a etiqueta `v<número da versão>` (por exemplo `v2`).

Aqui ficam apenas os arquivos de instalação. O código-fonte não está neste repositório, e os arquivos publicados não trazem chaves, nomes nem configurações pessoais.
